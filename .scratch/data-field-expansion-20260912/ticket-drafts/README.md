## 范围与执行边界

- 字段计数为原有 12 + 每日入口 16 + 存量 16 + TTM 19 + 指标首批 6 + 指标其余 157 = **226**。其中 close_raw 复用既有未复权价格身份，不能重复新增身份或从 daily_basic 逐行补价。
- 01 是用现有能力证明合同调整的前置重构；02—06 每张都包含来源到研究使用的完整路径。05 和 06 使用同一字段注册与可用性机制，6 项只是实施首批范围，不引入临时开关、第二版合同或另一份目录。
- 各能力票先用有界来源资格证据和固定数据证明闭环；07 才汇总完成整个声明研究范围的真实采集与覆盖验收。原始记录存在、字段可用、每个股票日非空是不同事实。
- 中间任务可在隔离环境单独演示和验证，**不单独面向生产发布**。开发从 main 建立隔离工作区，并最终集成到 main；部署分支只能从 main 合并。08 不允许绕过仓库的验证与发布规则。
- 保留原 12 项语义、原始历史、被引用 Generation、ResearchRun 结果和 DailyTrack 检查点。应用只使用当前合同，不增加双读双写或旧版本分支。确需持久化升级时，在拥有该变化的能力票完成显式迁移及保留数据的验证，08 汇总执行与回滚证据。
- Data 页维持四个顶层区块。字段目录、类别聚合与就绪信息会更新；不新增来源卡片或 TTM 期间差异界面。
- 真实来源资格未通过，保留事实和未完成状态；不能削减 226 项范围、换源或填值来宣布完成。来源事实由实施者核验，不要求用户猜测单位或接口行为。
- 各票使用仓库既有隔离验证入口，按其实际改变选择验证边界。确定性测试不依赖 TuShare 网络；真实来源资格单独保留脱敏证据。不得重置共享开发数据。完成标记遵守本地 tracker 的测试、review 和提交要求。
