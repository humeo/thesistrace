[TuShare指标定义](https://tushare.pro/document/2?doc_id=79)提供来源名称及供应商指标范围；实际单位和期间结合保存的数值对照与发行人披露。适用性以供应商实际返回为限：金融公司和非金融公司科目不同，某样本空值不自动证明全部该类公司不适用。fina_indicator没有可靠报告类型/公司类型字段，不伪造其合并范围或完整PIT历史。

## 权威映射与验证

- indicator-field-qualification-ledger.json：全部163项作者/来源映射、固定期间、源单位、规范单位、供应商范围、样本覆盖和证据指针。首批6项沿用05的资格；其余157项已通过06的有界资格、实现和消费者验收。
- indicator-catalog-audit.json：逐项对照实现与上述记录，核查来源列存在、字段身份唯一和DSL编译映射。该审计不独立证明每个资格判断正确，需独立审查。
- indicator-ratio-scale-crosschecks.json：保留实际操作数、匹配/差异、容差和失败假设。151项有数值假设，不将其当作通过数量。issuer证据和现金流关联对照覆盖其余证据边界。
- indicator-primary-report-crosschecks.json：发行人年报/半年报数值与保留指标的对照、页面/章节、单位及解释限制。
- indicator-free-cashflow-crosschecks.json：不同自由现金流假设与直接现金流来源的对照；所有未匹配假设仍保留。

所有字段读取供应商原始值，不在运行时使用这些对照公式补缺、重算或换源。选中最新可见报告为空即返回缺失，不回退旧非空记录。历史回填按已接受的公告对齐与后续观察修订规则使用，不宣称完全重建历史当时的供应商版本。

## 已解决的易混淆定义

| 字段 | 明确决定 | 证据及限制 |
| --- | --- | --- |
| gross_profit ← gross_margin | CNY累计毛利金额 | 30个累计营业收入减营业成本匹配；不是毛利率。 |
| impai_ttm | 百分数转小数，本年累计 | 30个累计减值损失/总收入匹配；TTM和单季替代假设保留差异。 |
| q_impair_to_gr_ttm | 百分数转小数，单季度 | 30个单季操作数匹配，不因ttm后缀标成TTM。 |
| equity_yoy | 百分数转小数，净资产同比 | 23个归母权益同比匹配，1处历史差异保留；不承诺通用分母/修订重建。 |
| salescash_to_or、ocf_to_or、ocf_to_opincome | 来源已为小数，不除100 | 各30个尺度匹配。 |
| q_salescash_to_or、q_ocf_to_sales、q_ocf_to_or | 来源百分数除100，单季 | 分别30/30/28个匹配；后两项分母分别为营业收入和经营活动净收益。 |
| ocf_to_profit | 百分数除100 | 分母是营业利润，不是净利润。 |
| dp_assets_to_eqt | 年初/期末均值的杜邦权益倍数 | 平均资产/平均归母权益30个匹配；期末替代假设不符。 |
| profit_to_op | 累计利润总额/供应商收入范围 | 总收入分母30个匹配，保留官方简述与样本范围差异。 |
| tangible_asset | CNY，供应商有形净权益范围 | 22个归母权益扣减相关无形科目匹配，不能介绍为资产总额扣无形资产。 |
| fixed_assets | CNY，供应商固定资产合计范围 | 与单个fix_assets_total并非同义；建设、工程物资、投资性房地产组成差异保留。 |
| invturn_days、arturn_days | 天，本报告累计周转期间 | 月数×30除供应商已舍入周转率各32个匹配，不采用自然日假设。 |
| rd_exp | CNY，累计研发投入合计 | 茅台2024年报和半年报费用化加资本化之和分别695376735.81、418062861.85元；不同于研发费用。 |
| roe_waa、roe_avg | 百分数转小数，报告累计期间 | 茅台半年报分别17.63、17.62，与披露加权和扣非加权值对应；roe_avg保留增发条件范围，不将样本对应推广成普遍选择算法。 |
| cash_ratio | 期末保守速动倍数 | 12个流动资产组成对照支持原尺度；其他分项差异保留，不改成货币资金单项比率。 |
| ebit_to_interest | 累计期间，倍数 | 万科年报和半年报，用EBIT除含资本化的利息支出减利息收入，分别匹配9.2368和5.1586；费用化利息单项不是该样本分母。 |

每股字段按CNY/share，期末权益类和累计/单季利润现金流类保持不同期间。年化回报不等于TTM；同比、单季同比、单季环比和较年初增长各有独立期间。百分数统一规范为小数，倍数保持原尺度。

历史管理费用与R&D分类、舍入、供应商调整及修订可能使简单三表重算不同。完整复算每个历史供应商值不是额外开放门槛；已核实的单位/期间不能掩盖未说明的范围差异，差异仍供审查。

## 自由现金流的最终证据

FCFF与现金流来源free_cashflow在31个可比样本相符，覆盖一季9、半年9、三季7、年报6；两处2018三季报差异（万科及上海机场）原样保留。现金流来源报告累计期间和金额尺度用于核实指标期间，不将另一来源当作运行时别名。

FCFE与同报告期间FCFF加借款、发债现金流再减偿债现金流在13个样本相符，覆盖四种报告期。最初忽略发债现金流的假设没有成功，证据保留。每股FCFF/FCFE各18个金额/期末股本匹配；运行时仍读取每股源列，不由金额字段重算。

上述关联是数值与期间证据，不承诺所有历史调整都遵循同一可复算算法，不将经营现金流减资本支出命名为严格FCFF。参考其他供应商的公式只用于形成待检验假设，不证明TuShare采用相同算法。
