# 08 — 每日按共同条件加减仓

**What to build:** Agent 可按市场或行业条件每天决定仓位，在选股周期之间于下一 Open 增减仓或清仓恢复，同时保持正确的目标与连续账户。

**Blocked by:** 05 — 用市场和申万一级行业指标构造共同条件；07 — 独立选股周期并支持固定账户仓位

**Status:** complete

- [x] Exposure 使用同一表达式 Module 的常量/共同每日数值，输出 0–1；不能直接用个股字段、股票 rank 或账户状态。Signal/Exposure 编辑器、补全、整份诊断、冻结输入声明各自作用域。
- [x] 每天 Close 计算 Exposure，与上次已决定值相比变化才触发下一 Open；无新选股且值未变时不因价格漂移或前次受阻自动交易。
- [x] 选股和 Exposure 同日变化合成一个最终目标、一次先卖后买；收盘保存决定模式、名单、相对权重和 Exposure，Open 才按实际净值形成金额/数量，不能同日 Open 使用当日 Close。
- [x] 非选股日减仓按实际持仓价值比例缩减；已低于目标时不反向买入，某股卖出受阻不额外卖其他股票补偿，阻单当日结束。
- [x] 非选股日加仓/从零恢复按保留名单和候选顺序补足缺口，不重选或为重置相对权重额外卖出；总买入预算受目标与实际差额、现金和费用约束，空仓期间的新名单被正确使用。
- [x] Signal、Exposure、共同指标和已有配权的真实依赖/窗口/预算一起准入；静态与数据就绪问题准确诊断，确定性非法结果不 clamp/默认 0/默认 1，失败 Advance 保留前次发布状态。
- [x] 真实 Run/Batch/Track 证明周期 5 下的中途增减仓、100%→30%→0→恢复、同日双触发、受阻与跨段继续；手算 6 万/4 万缩至总 3 万的目标为 1.8 万/1.2 万。
- [x] 末日和缓存恢复继续使用已冻结目标值，后续数据不重算旧决定；页面/MCP 显示固定规则、完成日期与目标/实际偏离，实际仓位不被声称为硬上限。
- [x] 状态采用单一当前合同；不把 20% 回撤偏好、止损或有状态 trade_when 加入规则。

## Notes

规格：每日 Exposure 全部触发/执行语义、联合准入、续算。

母规格：Agent Quant Research：信号评估、策略回测与前向追踪。遵循其当前合同与范围；每票直接交付当前合同，前端、MCP、验证随行为交付，不作为尾部补接工作。
