# 07 — 独立选股周期并支持固定账户仓位

**What to build:** Researcher 可以按自己的本金设置每若干 Session 选股、固定投入 70% 等比例，空仓期间仍保留最新名单，Run、Batch 和 Track 使用同一定义。

**Blocked by:** 02 — 按实际本金回测并延续同一账户；03 — 末日正常交易，追踪只追加新日期；04 — 让 Signal 支持比较、布尔和条件表达式

**Status:** ready-for-agent

- [ ] 公开周期统一为 selection_every_sessions，整数 1–20，持股数 1–100；表单/草稿/目录/HTTP/MCP/来源/Track 同步，不提供旧 rebalance_every_sessions 别名。
- [ ] 复用表达式 Module 验证常量 Exposure，接受有限 0–1 数值并冻结，默认 1；固定百分比只是同一表达式的编辑方式，本票不提前接受尚未实现的数据序列仓位。
- [ ] Target Selection 按周期保留候选顺序和 Relative Target Weights，本票实现等权；名单未变也有定期配置目标，目标不更新不因价格漂移交易。
- [ ] 目标金额为执行前 Net NAV 乘 Exposure，再应用合法数量、费用和现金检查，不乘当前现金；NAV10 万元、Exposure0.7 时股票目标 7 万元，实际配置可因费用取整偏离。
- [ ] Exposure0 形成连续现金账户并正常更新名单/权重，初始基线和投资区间不随真实成交与否变化；下次选股不表示账户永远只能在该时点交易。
- [ ] 周期相位、保留名单/权重、当前 Exposure 与待执行目标贯通 Run/Batch/Track 的已完成终态，分段和缓存恢复保持一致；旧已发布历史不覆盖。
- [ ] 新增 diagnose_research_spec 检查整份当前配置，复用准入编译/依赖/预算；不创建任务或占 pin，正式提交仍原子校验，局部诊断支持对应使用上下文。
- [ ] 字段和状态直接切换到当前合同；验证小账户/零仓位模块、真实发布与网页/MCP 冻结配置。
- [ ] 该票贯通完整固定仓位研究，配权只在目录宣告已实现的等权，不增加未来 target_weights 或空实现类型。
