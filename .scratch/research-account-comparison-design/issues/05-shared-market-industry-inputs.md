# 05 — 用市场和申万一级行业指标构造共同条件

**What to build:** 网页与 Agent 能发现并在 Signal 中使用本研究 Universe 及指定申万一级行业子集的共同收益和上涨占比，成员与统计口径可核对。

**Blocked by:** 04 — 让 Signal 支持比较、布尔和条件表达式

**Status:** complete

- [x] 首版提供所选 Liquidity Universe 与其中指定 SW2021 L1 行业的等权单 Session 收益、上涨占比；成员取各信号 Session 的历史 Universe Membership/Industry Classification，不再按 Alpha 或未来标签筛选。
- [x] 收益基于截至当日 Close 的完整、有限调整后 Close 单 Session 收益；零收益进上涨占比分母，缺少有效样本则指标缺失，同时保留成员数、有效数和排除原因。
- [x] 共同序列按日期对齐，广播参与每股 Signal；行业参数校验绑定正式目录身份，不允许动态任意证券查询或把股票向量任意压为标量。
- [x] Data/Research 目录、编辑器、MCP catalog 和结果来源显示真实范围：研究 Universe 内行业子集，不称全行业或官方指数；选择行业不修改选股 Universe。
- [x] 共同输入、历史成员、字段、定义及所需前一收益观察进入冻结 Data Generation、联合 Warm-up、数据就绪和资源预算；不读取可变 Benchmark 冒充研究输入。
- [x] 人工成员收益 10%、−2% 时等权收益 4%、上涨占比 1/2；验证零收益、空行业、历史改行业、Universe 外股票和未来价格扰动，普通/Batch/Track 输入含义一致。
- [x] 网页、HTTP/MCP 对未支持行业、不可用范围和非法参数给出同一定位诊断；不静默补行情、不新增官方指数外部采集或行业选股过滤。
- [x] 完成治理边界真实发布、计算及目录/编辑器交互验证；共同指标身份和来源采用当前合同。
