# 12 — 临时保存每日持仓，读取续期并安全清理

**What to build:** 正常回测和 Track 自动保存可查询的每日实际持仓，默认闲置 7 天过期并回收字节；账户结果和续算仍然完整可用。

**Blocked by:** 03 — 末日正常交易，追踪只追加新日期

**Status:** ready-for-agent

- [ ] Strategy Run 正常执行时按有界 Chunk 收集实际持股、执行股数、调整后单位、当时 Open 执行后估值/权重；Factor 不生成；空仓 Session 有覆盖，读取不拿最新价格重估。
- [ ] 每个 Run、Batch 子 Run 及每次成功 Advance 新增段单独保留，内容不可变、元数据独立；过期时间为成功发布/最后成功明细读取中较晚者加 7 天。
- [ ] 真实明细读取成功只续期实际读取单元，合法空仓读取同样续期；列表、摘要、状态、有效期查看、预取及健康检查不续期，新 Refresh 不续期旧段。
- [ ] 网页和 MCP 提供按日期/股票的有界查询、来源及 expires_at，区分 available、expired、not_recorded 与合法空仓；cursor 固定产物和来源，过期后不切别次运行或自动启动计算。 仅拥有者且具备对应读取 scope 才能读和续期，失败读取不续期；目录明确这项保留副作用。
- [ ] 临时持仓不是永久 Result/Checkpoint 的必需对象；过期仍可读指标/每日净值/终态/交易证据、正常继续 Track，也不为 TTL 额外永久 pin 行情。
- [ ] 读/续期与清理原子协调：读先获准可安全完成并续期，过期先完成则拒绝读；逻辑到期后即不可读，物理删除失败可重试而不复活。
- [ ] 撤销临时引用后复用 Publication 引用复核，只删除无人引用字节，保护永久 Result、Checkpoint 及其他有效产物；不得按共享桶年龄删除或把既有永久数据追溯标为可删。
- [ ] 可控时间证明 P 发布至 P+7 天、P+6 天读取延至 P+13 天、轮询不续期、子项/段互不续期；真实 PostgreSQL/RustFS 验证并发读删、引用保护、清理失败、取消及未完整暂存清理。
- [ ] 收集开启不改变账户/交易；量测持股数与研究长度增长时的内存、压缩字节、写入耗时和清理滞后，不能使用无限增长 ledger 或声称 TTL 消除写入峰值。
- [ ] 临时元数据/产物的当前合同及网页/MCP 验证随票完成，过期不影响永久结果及续算；不新增诊断服务或保留套餐。
