# 02 — 按实际本金回测并延续同一账户

**What to build:** Researcher 或 Agent 可以用 10 万或其他合法本金真实模拟账户，结果和后续 Track 使用该本金的现金、数量、费用及收益基线。

**Blocked by:** None — can start immediately

**Status:** complete

- [x] Strategy 输入要求0.01–1,000,000,000 元范围、最多两位小数的十进制 CNY Initial Cash；目录、表单、草稿、规范化接受值、HTTP/MCP 与结果 provenance 使用相同字段和约束。
- [x] 初始 Gross/Net Cash、数量与可负担性、成本占比和收益分母均使用接受后的 Initial Cash；不能只缩放最终收益额或保留隐藏 1000 万常量。
- [x] 每个 Strategy Batch 子 Run 拥有独立本金账户；DailyTrack 继承固定基线且每次 Refresh 不重新注资，源 Run 删除不使继承的模拟条件丢失。
- [x] 小于最小合法买入金额的本金允许成功形成现金账户；初始净值、未成交、现金和无法定义的风险统计如实显示，不为凑持仓借款。
- [x] 用同一主板单股、固定价格与既有数量/成本规则独立核算 10 万、1000 万的合法数量、佣金、余款及收益；例如一手金额超过 10 万时小账户不能买入而大账户可以，现金始终非负。
- [x] 当前请求必须显式记录实际本金，账户和后续追踪使用同一金额；不把不同本金的结果靠缩放或默认旧金额代替。
- [x] 通过真实 Run/Batch/Track 发布和网页/MCP 输入输出验证继承及冻结；同本金复算数值相同，Factor 的合同保持按当前 kind 合法性处理。
- [x] 本票独立完成相关接口、页面、定向测试及提交，不依赖后续 Exposure 或非等权功能才能使用。
