# 板块权限与10万元研究的边界

核查日期：2026-09-10。用户只确认研究本金100000元、可承受阶段性回撤约20%；尚未答复已开通哪些板块权限。

研究的“全部板块”覆盖沪深主板、创业板与科创板。投入本策略的10万元不等于用户证券账户总资产，不能由投入金额直接推断已开通或未开通的权限。

上交所现行2026年交易规则于2026-07-06生效；其个人科创板权限条款要求申请前20个交易日账户资产日均至少50万元及证券交易经验24个月以上。资产口径排除融资融券融入的证券和资金。[上交所现行规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)。

深交所投教关于新申请创业板权限的官方问答列出前20个交易日日均资产至少10万元和24个月交易经验等条件。这是新申请条件，不能替代对用户现有权限的确认。[深交所官方问答](https://www.szse.cn/www/investor/knowledge/t20200527_577693.html)。本轮搜索获得官方索引正文；打开该页面超时，未核验账户或券商办理状态。

因此增加“主板＋创业板、排除科创板”的假设情景，见[预先记录计划](account-board-plan.json)。它沿用原TOP3000和全池市场宽度，只在选股时应用可交易板块约束。与重新构建股票池、对可交易股票单独计算市场宽度是不同策略，本轮不做后者。

这两个10万元情景沿用2025-09-10至2026-08-27和每笔额外10bp成本。即便达标，也只是同一低成交额信号的权限情景，不新增独立经济家族。最终账本核验将逐项检查目标、成交和持仓均落在允许板块，结果列入[10万元报告](CAPITAL_REPLAY.md)。
