## 2. FIP：原定义支持条件关系，单独 ID 不构成增量

Da、Gurun、Warachka（2014）的原定义为 `ID = sign(PRET) × (p_neg − p_pos)`；PRET 是过去 12 个月中跳过最近一个月的累计收益，日收益频率来自相同形成期。美国 CRSP 主检验为 1927–2007，另有 1980 起子样本；先按 PRET 五分组，再按 ID 五分组，观察随后 6 个月。低 ID 的动量更强。原表 2A 中，赢家腿的连续/离散组收益为 9.56%/7.53%，输家腿为 3.62%/9.60%；多空改善中较大部分来自输家腿，不能全部算成只做多优势。[作者托管的正式论文，§1、§2、表 2](https://academicweb.nd.edu/~zda/Frog.pdf)

**代数去重，而非新的实证结论。** 令 `S = mean(sign(r)) = p_pos − p_neg`，则 `ID = −sign(PRET) × S`。在 PRET 为正的股票中，按低 ID 排序就是按高 S 排序。故把既有连续性公式包装为 `-rank(ID)`，并没有引入新的原始信息；若不限定赢家，低 ID 同时包含连续下跌的输家，也不能把它直接当只做多评分。

此外，对同一组日收益进行排列，累计复利收益和 S 都不变，因此 ID 不识别这些日收益的时间顺序；AR(1) 和价格路径回归却可能改变。把 FIP 简称“路径平滑”会掩盖这个区别。`−PRET × ID = abs(PRET) × S` 也只是两个已有输入的交互变换，不能凭代数相乘就称发现第三种原始信息。

后续一手研究给出两条相反方向的约束：Goyal、Jegadeesh、Subrahmanyam（2025 年卷期，2024-09 在线）的 1993–2020 年国际样本，含 22 个发达和 27 个新兴市场，对 `ID × MOM` 给出支持；但文中单独 MOM 在中国、日本、韩国不显著，国际结果不等于 A 股成立。该文按月预测，动量形成期同样跳过最近月。[期刊原文 §2、§4.3–4.5](https://academic.oup.com/rof/article/29/1/241/7772889)

Galvani（2024）正式发表的摘要则将 ID 与动量的负关系限定在 UP 市场。当前没有论文所需市场收益状态，本轮不将个股均线或横截面广度冒充该条件。检索同时出现的早期会议稿与正式摘要措辞不同，以下采用正式版本；本轮只核到摘要，未核完整样本起止和参数。[正式期刊页](https://www.sciencedirect.com/science/article/pii/S1544612324004045)

### 唯一候选：赢家条件内的收益符号连续性

候选键：`fip_winner_conditional_120_skip20`。其新增假设是：**在既有中期动量已经很强的共同有效样本内，频率连续性是否增加后续收益辨识度。** 不是再次检验普通动量或普通 S。

固定三个定义：

- `M = lag(close, 20) / lag(close, 120) - 1`，完全沿用已有动量端点。
- `S = lag(ts_mean(sign(pct_change(close, 1)), 100), 20)`。100 个日收益准确覆盖 M 的端点之间；把 60 改为 100 只为对齐既有形成期，不将这项改窗算作候选。
- 共同有效样本要求 M 与 S 都可用；在该样本的 M 排名严格高于 0.8、且 M 严格为正的股票中，按 S 从高到低排序。0.8 来自原研究五分组的赢家层；正收益约束是只做多改写，用来避免下跌市场中的“相对赢家”仍是连续下跌股票。

完整 DSL：

```text
rank(lag(ts_mean(sign(pct_change(close, 1)), 100), 20) + 0 * log(rank(lag(close, 20) / lag(close, 120) - 1 + 0 * lag(ts_mean(sign(pct_change(close, 1)), 100), 20)) - 0.8) + 0 * log(lag(close, 20) / lag(close, 120) - 1))
```

内层 `0 * S` 将 M 的分位排名限定在完整形成期可用的股票；`log` 仅将不满足严格门槛的股票标为缺失。当前代码规定非正 log 输入缺失、完整滚动窗口遇缺失即缺失、rank 不计入缺失值。因此不把停牌缺口填成零收益，合法零日收益的 `sign` 则仍为 0。分位边界有并列时按当前平均秩语义处理，不保证恰好 20% 入选。[算子与缺失语义](../../apps/core/src/thesistrace/research_kernel/alpha_builtins.py)

**这是明确的本地近似，不是 FIP 完整复现。** 原形成期约 11 个自然月，本候选使用现有 100 个交易日形成期及 20 日跳过期；原文多空和 6 个月持有均未照搬。静态有效回看为 120，需要对应完整历史，不能为了最新年本地数据不足而缩短窗口。本轮未调用研究 MCP 校验或提交；本地编译尝试因 uv 缓存读取权限失败，没有得到正式编译通过结果，后续预声明前仍需原生语言校验。[当前语言限制](../../apps/core/src/thesistrace/alpha_language/language.py)

**必要对照与停止条件。** 令 `G = 0 * log(rank(M + 0 * S) - 0.8) + 0 * log(M)`，这里 M、S、G 是说明记号，不是可直接提交的 DSL 标识符：

1. 同一入选池内普通动量：`rank(M + 0 * S + G)`。与候选使用相同的样本、现金暴露规则、持仓数和调仓间隔；否则不能区分“赢家过滤有用”与“过滤后 S 排序有用”。
2. 同形成期普通连续性：`rank(S + 0 * M)`，并保留原有 60 日连续性和原 M 的结果。前者仅是匹配形成期对照，不算新家族。
3. 风格归因至少看持仓与账户收益重合，比较已有 MAX、低波动和趋势切换。只有因子 IC 转正或总 Sharpe 上升，仍不足以证明独立。

后续如进入因子筛查，1/5/20 日全部保留，20 日作为当前平台近月诊断；原文的 6 个月效应并不能由 20 日标签证明。筛查不过则停止这个冻结定义，不改窗口、符号或分位门槛救结果。只做多候选须和第 1 项进行实际策略对照后，才讨论 TOP3000、10 万元、Sharpe > 1.2 与约 20% 回撤目标；原生研究账户与 10 万元可交易结果须继续分开报告。

**次日开盘可捕获性。** 本候选全部收益输入结束于 t−20，t 收盘后的计算不存在必须先买入才看得到的信息。若存在持续漂移，次日开盘后可以检验；但已有的 t 收盘至次日开盘变化不能计入新仓，论文的月度收盘收益也不证明平台的 next-open 收益。该判断只说明时点兼容，尚无本平台盈利证据。

### 2026 年新进展：TC 有理论增量，但本轮不改造成第二个近似候选

Cai、Li、Keasey 的《Trended Momentum》于 2026-07-07 列入 JFQA forthcoming，期刊公开的是 2026-06-30 最终稿。`TC = R²` 来自形成期日价格对确定时间趋势的回归；美国主样本 1926-01 至 2023-12，形成期为 t−11 至 t−1、跳过 t，至少 200 个日观察，持有 t+1 至 t+6。文中 TC 与 ID 的竞赛检验保留各自解释力，不能把 TC 当 S 的别名。[期刊最终稿 §II.B、§III、§IV](https://jfqa.org/wp-content/uploads/2026/07/26353_Trended_Momentum.pdf)；[期刊接收页面](https://jfqa.org/2026/07/07/trended-momentum/)

OLS 恒等式为 `TC = [sum((k−mean(k)) × (P_k−mean(P)))]² / [sum((k−mean(k))²) × sum((P_k−mean(P))²)]`。当前没有时间索引/趋势回归算子，按至少 200 个价格逐项展开加权和会超出节点、深度和长度预算。将它替换为 6/12 个价格抽样、均线差、端点收益除波动率，会改变原定义；本轮没有证据证明这些粗化代理保留了 TC 对 ID 的增量。因此不提出替代公式。原论文的月度、6 个月持有效应在时点上可以讨论 next-open 后漂移，但当前无法据此声称可忠实实现。

## 3. 52 周低点：与高点不同，但不能据“不同”直接确定可交易方向

George、Hwang（2004）的基准量是 `P/H52`，不是 `P/L52`。原研究使用 1963–2001 年 CRSP 股票，按该比率选高低 30% 的组合，按月形成、持有 6 个月；方向为近高点股票较强。这为已有 near-high 假设提供定义，不能推出低点买入或远离低点买入。[作者托管的正式论文 §I](https://www.bauer.uh.edu/tgeorge/papers/gh4-paper.pdf)

数学上，`P/L52 = (P/H52) × (H52/L52)`。在同一个近高点程度下，低点比率额外引入年度极值区间；它不是 near-high 的单调变换。但这也意味着不加控制的低点排序可能只是年度振幅、过去收益或反转暴露。用 `rank(P/L52)` 或其负号跑一次，仍需同时控制 P/H52、H52/L52、累计收益及波动；换一个极值算子本身不证明锚定机制。

Lasfer、Ye（2024）分别定义 `P/H52`、`P/L52`，并使用距高低点的天数与内幕净交易条件。美国样本 1994–2018，11,090 家公司；按月再平衡，考察 1/6/12 个月。其表 2 显示：不含内幕交易条件时，“买近高、卖近低”的距离排序多空差不显著；加入新近程度后表现不同。故近低点、刚创新低、内部人卖出不能视为同一变量。[期刊全文 §2、§3.1–3.2、表 2](https://onlinelibrary.wiley.com/doi/full/10.1111/fire.12371)

原文正文 Eq.4 写 `Rec = 1 − N/365`，附录又出现 364 及低点行误写高点的文字差异；此处不静默选一个版本替原文补齐。当前 DSL 缺少极值发生日的 argmin/argmax 与自然日距离，也没有内幕交易及披露时点。`close/ts_min(close,252)` 只保留距离，不保留上述条件；`close == rolling low` 一类事件近似还会改变并列低点处理和持有定义。因此**不保留单独 52 周低点候选**。纯价格信号可在 next-open 后检验，内幕交易当日计算的收益却不能在缺少公告可见时间时认作外部投资者可得。

### 2026 年联合高低点 PTA：值得记录，尚不足以提交

Chen 等（2026）的 PTA 明确同时使用 price-to-high 与 price-to-low 信息。美国股票样本 1963-07 至 2020-12；设计是先在 t−1 月末测锚，再按 t 月收益找赢家，观察 t+1 月。摘要/引言支持高 PTA 赢家强于低 PTA 赢家；这不是低点附近无条件反转。**本轮未取得可核实的 PTA 完整数学公式，不能自行认定它是两个比率的均值或均价锚。**[出版商方法与引言片段](https://www.sciencedirect.com/science/article/pii/S0378426626000178)；[作者 SSRN 版本页](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=4549819)

即便以后取得原公式，完整 252 交易日锚再滞后约 20 日，有效回看约 271，超过当前 252；把锚改为不滞后，会让 t 月涨幅进入“事前锚”，改变论文要识别的先后关系。缩短年度窗口、移掉滞后、凭摘要拼接双比率，当前都不足以成为冻结候选。它在 next-open 后的月度持有原则上可检验，但不能只引用多空月收益作为本平台只做多收益。
