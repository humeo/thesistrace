# 非流动性正比例变体的公开账户路径核对

2026-09-10 核对。d013 与 d079 分别为 `rank(ts_mean(abs(pct_change(close, 1)) / amount, 20))` 和 `rank(ts_mean(abs(pct_change(close, 1)) * 100000000 / amount, 20))`。冻结清单继续保留两个字面定义、四个账户案例；经济家族计数不应把该正比例变体当作独立发现。

两对账户均为 TOP3000、none、2025-09-10 至 2026-09-09、每20个交易日调仓，分别持有10只或20只。数据与执行契约完全一致，原生本金1000万元。分别读取每个 Result 的五页公开逐日观察，每个账户242点，没有遗漏或重复日期。

|持仓|原式 / 倍数变体 Sharpe|累计净收益|最大回撤|比较结果|
|---|---:|---:|---:|---|
|10只|0.282218|3.6238%|33.1008%|242行、全部10个公开字段精确相同|
|20只|0.012346|−3.6721%|30.4038%|242行、全部10个公开字段精确相同|

相同字段包括日期、毛/净净值、现金、当日费用、持仓数量、最大单股权重及三类交易拒绝数。两对因子摘要及完整策略 metrics 也分别精确一致。此处没有逐笔成交或证券名单比较，不能把持仓数量相同扩展为已独立核实全部持仓身份。

四个路径另用50位 Decimal、241个相邻净值收益区间，独立重算 Sharpe、运行峰值回撤、累计收益和费用。Sharpe 最大绝对差约5.56e−17，其余三项与 MCP 数值转换后精确相同。两种持仓均未通过本轮门槛，也均超过20%回撤。这不是10万元账户验证。

数学上，在有限非缺失数据、没有溢出且不改变比较关系时，正比例缩放不改变排序。本次证据另外证明了指定数据、日期与原生执行契约下的公开账户路径一致；不声称所有浮点输入都完全等价，也未独立重建源行情。

NYU V-Lab 的方法说明也明确把成交额单位缩放作为可读性选择，并使用22日移动均值。这里保留先前研究的20日窗口、人民币成交额及TopN多头构造，不能称为原文投资组合的完整复现。[V-Lab 方法说明，2026-09-10读取](https://vlab.stern.nyu.edu/docs/liquidity/ILLIQ-HIST)。
