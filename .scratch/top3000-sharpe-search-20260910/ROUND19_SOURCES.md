核查日期：2026-09-10。已读取 [factors.csv](factors.csv)、[round7-plan.json](round7-plan.json)、[round13-plan.json](round13-plan.json)、[round18-plan.json](round18-plan.json)；去重快照为213条记录、80个字面公式。已覆盖 MAX、下行半方差、低波动、普通反转／动量、上涨天数比例、日内／隔夜均值与波动、年度高点、WQ量价关系、成交额变异系数、CHL价差及财务质量等。以下保留的是**两个尚未检验的增量假设，不是两个已经独立成立的 Alpha 家族**。没有为了凑数再增加偏度或趋势窗口。

两个窗口均为本次固定选择，不是论文给出的最优参数。这里只读代码确认 `pct_change`、`lag`、`ts_mean`、`ts_std`、`rank` 可用；`ts_std` 是总体标准差，滚动算子要求完整窗口。没有调用 MCP 诊断或提交研究，下面公式仍需主任务验证准入。[当前算子定义](../../apps/core/src/thesistrace/research_kernel/alpha_builtins.py)；[当前表达式限制](../../apps/core/src/thesistrace/alpha_language/language.py)

**1. 一阶自回归的预测增量：`ar1_increment60`。**

近期一手证据并不支持固定认为动量或反转永远有效。Hu、Jin、Wang 的工作论文2025年上传、2026年1月修订，研究1897–2024美国市场日收益，发现自相关随时期变号，负收益后的反转更明显。作者报告的指数多空日调仓策略 Sharpe 为0.54；它不是A股个股策略，也没有给出本项目所需的1.2保证。这里只核实了作者提交的摘要，不能据此复现其完整交易规则。[作者提交记录](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=5314371)

Ahn、Hambusch、Hong（2026年1月）使用 `r_t = rho * r_(t-1) + epsilon_t` 的AR(1)框架及美国、澳大利亚指数数据，指出重叠多期收益可夸大测得的动量强度。这提供了一个更窄的检验理由：从互不重叠的一日收益构造滞后一阶关系，不能用重叠20日收益之间的高相关证明预测能力。下述60日滚动估计、个股横截面排序及交易规则均为本项目自定，不属于原论文复现。[作者开放原文及附录A](https://doi.org/10.3390/jrfm19010046)

另一个机制限制来自 Anderson、Eom、Hahn、Park（2013）：NYSE逐笔研究将自相关分为非同步交易、买卖价差反弹、价格调整和变化的风险补偿；正负自相关不自动等于可交易的信息延迟。当前没有逐笔报价或成交分隔子区间，无法完成其识别，只能检验交易成本后的结果。[出版商摘要](https://www.sciencedirect.com/science/article/abs/pii/S0927539813000625)

令 `r=pct_change(close,1)`、`x=lag(r,1)`，用截至信号日的60组 `(x,r)`：

```text
beta = (mean(r*x) - mean(r)*mean(x)) / var(x)
increment = beta * (r_today - mean(x))
```

这是含截距OLS的一步预测相对训练样本 `mean(r)` 的增量；完整预测还需加上 `mean(r)`，此处刻意不把已有均值动量混成新信号。`beta>0` 时延续最近相对均值的变化，`beta<0` 时反转。它对收益的排列敏感：重新排列相同的一组日收益可以保持总复利收益、波动、MAX及上涨天数不变，却改变相邻收益乘积。这是相对已有信号的数学增量，**不等于已经证明独立经济收益来源**。

完整待诊断公式：

```text
rank(((ts_mean(pct_change(close, 1) * lag(pct_change(close, 1), 1), 60) - ts_mean(pct_change(close, 1), 60) * ts_mean(lag(pct_change(close, 1), 1), 60)) / (ts_std(lag(pct_change(close, 1), 1), 60) * ts_std(lag(pct_change(close, 1), 1), 60))) * (pct_change(close, 1) - ts_mean(lag(pct_change(close, 1), 1), 60)))
```

按当前算子的历史长度规则，该表达式有效回看61个交易日，需要62个收盘价。分母为零应保持无效，不加常数制造信号。可同时保留以下**旧反转机制的覆盖匹配对照**，不计新家族：

```text
-rank(pct_change(close, 1) + 0 * (1 / ts_std(lag(pct_change(close, 1), 1), 60)))
```

时点与失败边界：信号包含 `r_t`，只能在`t`收盘后得知，最早`t+1`开盘执行；没有在信号日收盘成交，也没有赚到尚未持仓的`t`收盘至`t+1`开盘收益。60组样本的系数可能很不稳定，极端收益、涨跌停及停牌会影响估计；不能把滚动估计当作可靠市场状态识别。先分别读取1／5／20日因子结果，若只在1日有效，不能直接宣称20日持有可兑现。实际短周期策略必须另验最低佣金、换手与10万元整手约束。负号镜像或更换估计窗口仍是同一假设。

**2. 历史波动率稳定性：`historical_vol_instability20_60_low`。**

Baltussen、van Bekkum、van der Grient（2018）的原始 vol-of-vol 定义是过去20日**期权隐含波动率**的标准差除以同期均值，主样本为1996年1月–2014年10月美国股票，并检验欧洲市场。其隐含波动率来自接近平值、约30日到期的看涨与看跌期权；低 vol-of-vol 对应较好的后续股票表现。作者强调期权价格的前瞻性，这正是日线历史波动率不具备的部分。[作者版论文 §II、表1](https://personal.eur.nl/vanbekkum/2018JFQA_unknown_unknowns.pdf)；[正式出版记录](https://www.cambridge.org/core/journals/journal-of-financial-and-quantitative-analysis/article/unknown-unknowns-uncertainty-about-risk-and-stock-returns/6E0E98349D20C1DCF67F3A0452361B80)

这里只提出一个明确不同的、可证伪的日线代理：先算20日收益波动率，再算过去60日这些波动率的变异系数。

```text
-rank(ts_std(ts_std(pct_change(close, 1), 20), 60) / ts_mean(ts_std(pct_change(close, 1), 20), 60))
```

有效回看79个交易日，需要80个收盘价。分母为零保持无效。所有嵌套窗口终止于信号日，最早下一交易日开盘执行。外层60日是本轮对风险变化的固定观察长度，不是原论文20日窗口的复现。

相比旧 `lowvol20`，这个比例对整段收益按正比例缩放不变，因而不直接奖励低波动的绝对水平；相比旧 `std20/std120` 状态，它衡量一段时间内波动估计的稳定程度，而非近期相对长期的上升／下降方向。但两者仍可能选中相近股票，必须检查分数、持仓及账户收益相关性，不能靠公式不同就增加独立家族数。覆盖匹配的旧低波动对照可写为：

```text
-rank(ts_std(pct_change(close, 1), 20) + 0 * (1 / ts_mean(ts_std(pct_change(close, 1), 20), 60)))
```

负面边界：20日波动窗口高度重叠，使历史波动路径机械平滑；外层变异也可能仅记录极端日进入／离开窗口的影响。滚动标准差是历史风险估计，不是期权隐含预期、风险溢价或直接的不确定性观测。原文支持的是隐含变量，不能将其股票收益差外推给这里的代理。当前尚无一手证据证明这个精确的20／60日线规则能在TOP3000提供独立收益。若它不能胜过覆盖匹配的低波动对照，或收益完全重合，应记为防御风险家族的无增量分解。

**本轮明确排除的方向。**

| 方向 | 排除原因与一手依据 |
|---|---|
| 再做 Frog-in-the-pan／上涨天数比例 | Da、Gurun、Warachka（2014）原式 `ID=sign(PRET)*(negative_fraction-positive_fraction)`，并以跳过最近月的过去12个月收益条件分组。在相同正动量条件下，低ID就是偏好更多上涨日；已有 `trend_consistency60` 和动量。改窗口或相乘可作条件对照，但不足以计新家族，也不测相邻收益的顺序。[作者版式(1)](https://academicweb.nd.edu/~zda/Frog.pdf) |
| 将2025中国隐含偏度论文改称日线偏度 | Zhou、Roh、Xu（2025）使用上证50 ETF期权提取上尾／下尾隐含偏度，发现总隐含偏度的横截面预测很弱、分解后方向不同。当前缺期权数据，`mean(r^3)/std(r)^3`不能复现这个变量。[出版商摘要](https://onlinelibrary.wiley.com/doi/abs/10.1002/fut.70012) |
| 把普通历史三阶偏度当新的已证实彩票机制 | Dai等（2023）的中国结果以日内数据构造已实现偏度，并且控制相对有符号跳跃方差后，该效应消失。2024年中国A股熵不对称论文也报告普通三阶偏度关系不明确。日频原始偏度可以计算，但不是这些文献的变量；已有MAX／下行风险，本轮不凭“第三阶”就增加独立经济家族。[2023原始研究](https://www.sciencedirect.com/science/article/pii/S1544612323007353)；[2024原始研究](https://www.sciencedirect.com/science/article/pii/S1544612324003477) |
| 熵不对称／公司特有偏度／跳跃分解 | 2024熵论文需要分布、众数、非参数估计与重采样；当前DSL缺这些算子。公司特有收益与市场偏度还需要因子／市场收益，精确跳跃分解需要日内数据。不能用上涨日比例冒充熵、用原始收益冒充残差，或用一个日涨幅冒充可识别跳跃。[2024原始研究的方法与限制](https://www.sciencedirect.com/science/article/pii/S1544612324003477) |

检验顺序建议仅保留上述两个固定候选及必要的覆盖匹配对照，先看各期限有效日数、同日配对的分组收益差、最高组与邻组关系，再决定是否做实际Top-N账户。不要把不同有效日期下的两个组均值相减当作可投资多空收益；因子IC和ICIR也不是组合Sharpe。原生1000万元结果、最新日期、10万元成本与最大回撤20%的检验仍须分别给出证据。以上文献均不能替代这些检验。
