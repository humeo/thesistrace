# 04 — 增量压缩与超长历史续接

**What to build:** 已压缩的 Agent Chat Session 继续积累消息后，能够完整处理多批历史和超长任务，再发布一份新的 M/S 并准确续接；重启、Continue、ask_user 和模型切换不会丢失有效上下文或暗中改写前缀。

**Blocked by:** 03 — 首次压缩后继续回答

**Status:** ready-for-agent

依据：[spec](../spec.md) 第 1、3—6 节。复用 03 已贯通的调度、候选、事务和继续推理路径；本票交付第二次及后续周期、完整长历史覆盖和会话恢复，不另建调度器。01 经 03 传递依赖；工具新分页契约不阻塞本票。

## Acceptance criteria

- [ ] 第二次及后续周期冻结新水位，从前一快照的有效原文与新增消息确定 R/E。E 排除已处理原文、仍固定条目及无效截断正文；固定项只在下一次压缩重新判定，解除固定且位于尾部前方后才处理一次，不重复摘要或漏掉边界前请求。
- [ ] 按当前模型合法请求空间分批；每批完整计入辅助指令、旧 M/S、选中原文、协议与推理/输出额度，持续记录来源和处理位置直至覆盖全部 E。不得把整批原文未经预算直接交给单 thread 同步 OM。
- [ ] 普通批次在完整消息/工具组边界结束；单条待摘要文本超出输入预算时，仅在辅助摘要输入中按带来源标识的片段拆分后归并，原始消息及工具配对保持不变。不使用 Observer 约 10k tokens 或 Pi 2000 字符默认工具截断替代完整覆盖。
- [ ] Observer 结合旧 M 逐批追加有效事实、约束、决策及资源引用；每批合并后检查 M，超过 floor(T / 8) 才在本周期 Reflect 至 floor(floor(T / 8) / 2) 以内，未超过不反思。空 M 合法，易变任务状态仅写 S，最新权威工具结果优先于旧记忆。
- [ ] 首次 S 沿用 03 模板，增量 S 使用 Pi 式更新模板读取旧 S、本次全部原始 E 和候选 M 一致性参考；不能只总结已经有损的 M。保留目标、约束、完成/进行中/阻塞状态、决策、下一步、ResearchRun/Result/数据版本 ID、请求 ID、游标及绑定条件、参数与错误。
- [ ] 保留边界位于超长轮次中时，分别处理更早历史及轮次前半段，再合成一份预算内 S，为保留后半段补齐当前请求和前情；当前请求的只读参考不推进处理水位。所有阶段先暂存候选，不产生可见的中间快照。
- [ ] 每次调用使用当前 Run 模型和 effort，并受共同 usage、Provider 时限、剩余 Run 时间与取消控制；辅助调用无业务工具。候选超长最多一次纠正，length、Reflector/S 失败、取消或总时间不足时停止整个周期，不发布部分结果。
- [ ] 最后核验 M/S 格式、关键续接依据、最终文本预算及完整输入低于 T 且 D 合法，再沿用 03 的事务一次性发布。无法缩减必须保留的输入或工具组时明确失败，不循环；取消、并发追加和 revision 竞争不能丢消息或推进半份边界。
- [ ] 两次成功周期之间 F/M/S/R 的字节内容和顺序固定，N 只追加；跨日期、重启、Continue、工具恢复及 ask_user 读取完整固定引用与有效尾部，不做 50 条或滑动窗口裁剪，内部控制消息有稳定身份且不重复或出现在浏览器用户消息中。
- [ ] 保持现有 Run 生命周期：启动时将崩溃遗留的 running Run 标失败，重启只恢复会话上下文；Continue 仅允许主动停止后的新 Run，ask_user 恢复沿用同 Run。不新增崩溃自动续跑。
- [ ] 模型/工具定义/权限变化重新校验预算及可用工具，允许因此改变 F；不为缓存保留已撤销权限。旧 M/S 在完整请求能容纳时复用，新文本预算只约束新生成快照，不因切换立即改写。
- [ ] C < K 时复用已有 M/S、固定项和完整有效尾部；I 超过 T 但 D 合法仍可推理，无合法空间则报错，所有入口均无辅助请求。C >= K 时恢复普通规则；不启动模型切换专用旧 M/S 分段重整，旧 M/S 无法进入合法辅助请求则明确失败，不借用其他模型、删快照、裁剪历史或自动回切选择。
- [ ] 通过 Scripted/Fake 验证完整 E 多批覆盖、条件 Reflector、增量与长轮次 S、中文长文本、固定项解除后只处理一次，以及最后一个大结果和整批工具越界后的实际继续推理。固定研究案例断言关键续读依据，不能以 Fake 文本通过代替真实模型保真度评估。
- [ ] 使用隔离 PostgreSQL 验证第二次提交、部分失败、并发和跨进程恢复；捕获 Provider payload 验证跨日期/恢复/切换的前缀及小窗口零辅助请求，完成相关页面错误/控制消息组件检查与 lint/typecheck。缓存前缀比较和 cached_tokens 分开记录，不承诺相同前缀必然命中。
- [ ] 在 03 所在隔离集成工作区继续实现，不把中间单批版本独立发布；本票独立 review、提交，移除单批阶段尚未覆盖的路径限制而非新增兼容或 fallback。保留原始历史、无关工作与 thesistrace-dev 数据，最终交付仍受 06 约束。
