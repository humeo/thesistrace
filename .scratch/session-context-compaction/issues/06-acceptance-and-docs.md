# 06 — 最终集成验收与交付

**What to build:** Researcher 能在同一 Agent Chat Session 完成有界工具读取、首次及增量压缩、稳定续接和一次截断恢复；交付包含可追溯的工程证据、独立的摘要质量评估及与实际行为一致的运行说明。

**Blocked by:** 02 — 有界工具结果与完整续读；05 — 截断后最多恢复一次

**Status:** ready-for-agent

依据：[spec](../spec.md) 第 9 节及完整需求。本票汇合 02 与 01 → 03 → 04 → 05 两条已验收链路，不以最终验收代替各票功能开发。spec 的需求与历史阶段索引原样保留；执行顺序以用户此次确认的各票 Blocked by 为准，01/03/04 通过 05 传递阻塞本票。

## Acceptance criteria

- [ ] 01—05 的功能、对应验证、review 发现与独立提交均已完成，验收证据说明版本、命令、退出结果及未验证范围。发现行为缺口归回负责票修复并复验，不把未完成的生成、存储、分页或恢复留到此票补开发。
- [ ] 在已验证的隔离集成版本上串联真实 Core/MCP 页与 Agent Chat：目录/文件夹续读、研究结果读取、小型操作回执、最后一个大工具结果及多工具累计越界后压缩并继续回答；页大小、游标、数值与成功操作身份均保持正确。
- [ ] 汇总 C=65535、65536、65537、自定义 K、I 在 90% 两侧及边界、模型切换和无合法 D 的证据。小窗口全路径零辅助调用，超过 90% 但仍可容纳的请求继续，放不下保留历史/快照/模型选择并明确报错；切回合格模型恢复普通规则。
- [ ] 汇总完整 E 分批、长轮次、空 M、条件 Reflector、准确资源/请求/游标与错误、固定项释放，以及 M/S 部分失败、取消、并发追加、revision 竞争的证据；真实 PostgreSQL 证明提交与恢复不产生半份快照或跨 Session 注入。
- [ ] 捕获实际 Provider payload，证明动态 D、合法长生成、必要协议与单份 canonical 工具结果；比较两次压缩间 F/M/S/R 及追加 N，覆盖跨日期、重启、Continue、ask_user。结构性前缀稳定与实际 cached_tokens 分开报告，不保证每次缓存命中。
- [ ] 完成真实浏览器关键闭环：普通压缩后继续回答、截断内容、独立替代答案、恢复中/成功/失败、刷新后状态、内部控制消息隐藏；已成功工具与后续推理失败分别可见，小窗口禁用压缩不显示为正在恢复。
- [ ] 汇总每逻辑步骤最多一次恢复、同 Run 计数不重置、错误类型切换不另获额度、无改善/用满 P/取消即停的证据；所有 length 分支不执行本步骤工具，此前成功操作不重放，崩溃后原 Run 不自动续跑。
- [ ] 复核并删除最终集成中遗留的原生独立 OM 调度、后台/空闲提取、动态日期前缀、额外 50 条裁剪、8192/累计 256 KiB 生成限制、跨 Session 共享、专用小模型重整及任何中间阶段限制；不得新增兼容、迁移或 fallback 路径。
- [ ] 检查已有观测记录涵盖压缩前后 tokens、耗时、逐调用 usage、估计偏差、工具页大小、恢复次数和缓存用量；不包含敏感原文、工具业务正文或 M/S 文本，内容仍只存于具备所有权约束的领域/会话存储。
- [ ] 对固定研究案例独立评估首次、增量和长轮次摘要的关键事实保留、续读正确性及错误保留，记录模型/effort、输入规模、成功与失败、成本和时延。工程测试使用 Scripted/Fake/Replay；未经实际模型评估不能声称摘要保真度通过，未完成的必需评估不能将本票标 complete。
- [ ] 更新与当前实现一致的模型配置、小窗口门槛、上下文/工具预算、会话生命周期、失败提示、研究 Agent 评估和 Mastra patch 说明，移除旧单层摘要或阈值描述；维护配置、契约示例与运行入口同步。
- [ ] 各票定向验证通过后，在最终集成版本执行 pnpm check 与 pnpm test:image-smoke；使用仓库隔离依赖/浏览器入口，保存失败命令和证据。只在相关变化或失败产生新疑点时扩大或复跑，不以重复整套验收掩盖未定位问题。
- [ ] 不重置或删除 thesistrace-dev 容器数据、数据卷或 Dataset Head；仅清理本次创建的隔离测试资源，保留无关工作区改动。最终 review 关闭、验证及提交完成后才可将本票标 complete；本次拆票发布不修改父 spec 或其状态。
