# ThesisTrace Core

The Python application owns the module-first Core API and Research, Batch Research,
Daily Track and Data Operator Workers. They share this package and final image.

Run repository lifecycle and test commands from the [workspace root](../../README.md).
Use `uv run --project apps/core` for a Core command from that root. Tests and
benchmarks live beside the application; shared product fixtures live in `tests/fixtures/`.
