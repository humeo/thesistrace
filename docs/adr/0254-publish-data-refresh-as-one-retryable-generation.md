# Publish Data Refresh as one retryable Generation

Data Refresh prepares Market, Financial and Industry families in order against one fixed request and publishes their validated Generation together with its Benchmark Snapshot through one Dataset Head switch. Failed preparation preserves the accepted version; durable attempts may reuse validated preparation from the same source Generation, while incomplete financial collection blocks publication and crash recovery reconciles the actual published identity before retrying. This supersedes independent family publication in ADR-0181 and extends ADR-0240: the Operator receives one operation, one review, one publication result and an explicit Retry, trading partial freshness for a complete release boundary. Retry history expires as a complete family only after every attempt is terminal and outside retention, so collection cannot detach a failed attempt from a successful sibling. Cleanup batches count these families.
