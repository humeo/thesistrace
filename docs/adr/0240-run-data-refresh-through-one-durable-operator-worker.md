# Run Data Refresh through one durable Operator Worker

Console and private CLI submit Market, Financial, and Industry Refresh to one durable FIFO processed by a single Data Operator Worker. Submission records acceptance independently of execution, while fenced recovery reconciles prior publication and explicit Retry creates a new operation instead of reopening terminal history, trading refresh concurrency for ordered source access and one Dataset Head publication boundary. Recent operation receipts are retained independently of Data Generation retention so operational history cannot prevent data collection.
