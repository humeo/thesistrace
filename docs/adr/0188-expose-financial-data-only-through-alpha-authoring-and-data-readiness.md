# Expose financial data only through Alpha authoring and Data readiness

The financial user surface exposes the six accepted Session-Aligned Financial
Fields and `rank` through the Alpha Authoring Catalog, plus Financial Coverage
and Financial Research Readiness through Data Overview. There is no separate
multi-factor editor, company-statement explorer, Raw Financial Batch viewer,
arbitrary Canonical field query, or second financial authoring interface.

Complete Tushare statement fields and source evidence remain behind the
Data-owned boundary for audit without automatically becoming authorable. This
keeps research on the same Formula, ResearchRun, and DailyTrack path instead of
coupling executable financial fields to a separate reporting product.
