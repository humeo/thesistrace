# Return correctable Research rejection as a structured MCP outcome

Alpha Diagnostics and ResearchRun or Research Batch admission rejection are
typed successful Tool outcomes because a Research Agent can correct the input.
Missing or forbidden resources, lifecycle and idempotency conflicts, temporary
unavailability, and sanitized internal failures are typed Tool errors with
stable codes and explicit retry guidance; no MCP response exposes SQL, paths,
tracebacks, credentials, or string-encoded JSON contracts.
