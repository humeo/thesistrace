# Give statement-derived TTM flows distinct field identities

New statement-derived rolling twelve-month flows use explicit TTM Field identities while existing annual Fields retain their meaning. Each TTM value is reconstructed from period- and scope-matched source versions visible to the Research Session; missing required components remain missing rather than substituting an annual value or aggregating daily forward-filled observations.

For these fields, retain the minimal pre-start component closure required throughout the declared Financial Coverage, alongside the seeds needed by existing fields. This extends [ADR-0184](0184-start-financial-coverage-in-2010-with-minimal-pre-start-seeds.md)'s start-boundary rule for the new TTM dependencies without enabling pre-2010 research.
