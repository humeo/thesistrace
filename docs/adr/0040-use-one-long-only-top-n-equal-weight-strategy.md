# Keep score-based selection as a built-in long-only Strategy

The built-in score-based Strategy selects the highest eligible Alpha Values, uses an explicit Portfolio Weighting rule for Relative Target Weights, and applies Target Exposure to leave the remainder in cash. Equal weighting is its default, while independent exposure changes preserve the retained selection and actual-holdings behavior defined in [ADR-0042](0042-use-only-scheduled-alpha-snapshots-for-periodic-full-rebalancing.md). Under [ADR-0250](0250-admit-strategy-programs-with-explicit-simulation-coordinates.md), this is one built-in Framework configuration rather than the only permitted Strategy; long-only, unlevered A-share simulation remains the product boundary for both modes.
