# Share bounded Batch calculation and recover complete tasks

A Research Batch atomically admits ordinary ResearchRuns with a shared scope and Data Generation; compatible requests share Data and Alpha calculation, Factor calculation belongs only to Factor Evaluation requests, and each item owns its own Result. Execution uses bounded full-Universe slices, but durable recovery preserves only complete Alpha tasks with any explicitly requested Factor evaluation, or complete item Results, accepting recomputation of incomplete tasks to avoid making slice state another research authority. Only classified transient failures retry; resource exhaustion and deterministic failures terminate the unchanged work.
