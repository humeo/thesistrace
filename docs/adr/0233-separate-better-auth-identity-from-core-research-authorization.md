# Separate Better Auth identity from Core Research authorization behind one origin

ThesisTrace exposes one Caddy origin that serves the Vite application and routes Auth and Core APIs without stripping their paths. A dedicated Hono and Better Auth service owns invite-only email/password identity, Login Sessions, and authentication cookies, while FastAPI Core accepts identity only through bounded Session verification and remains the sole authority for Research Ownership; neither runtime role may read the other's schema. This deliberately rejects embedded Python authentication, proxy identity headers, JWT authorization, Organizations, and RBAC in exchange for one internal verification call per Core request, because immediate revocation and a narrow ownership boundary matter more than cached identity or multi-tenant abstractions.
