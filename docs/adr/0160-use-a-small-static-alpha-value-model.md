# Use a small static Alpha value model

Alpha expressions use a closed static model that distinguishes numeric and Boolean values from their constant, shared-session, or instrument-session scope, alongside bounded Window arguments and complete Builtin signatures. Signal produces instrument scores while Exposure produces one numeric account allocation per Session; shared conditions can participate in Signal through defined broadcast rules, but stock vectors cannot implicitly become account scalars. Comparisons and pure conditional selection expand Alpha expressions without introducing a second evaluator, unbounded state, or arbitrary Python values. Admission checks the output required by each use site rather than applying the former Numeric-Series-only root rule to every expression.
