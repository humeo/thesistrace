# Separate scheduled stock selection from exposure adjustments

Selection Interval governs Target Selection Updates rather than all account trading: each update refreshes the ranked stock list and configured Relative Target Weights, even during zero exposure or when membership is unchanged, with execution at the following Open. A changed Target Exposure independently requests an adjustment at the following Open; increases use the latest retained Target Selection, reductions between selection updates scale Actual Holdings proportionally, and price drift alone does not request another adjustment. Retaining selection independently of actual holdings permits recovery from an all-cash account without silently selecting stocks again; daily Alpha evaluation, the daily meaning of any requested Factor Evaluation, and DailyTrack's original selection phase remain intact.
