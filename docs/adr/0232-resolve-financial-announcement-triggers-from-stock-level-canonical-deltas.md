# Resolve financial announcement triggers from stock-level Canonical deltas

ADR-0219 continues to define CNINFO as discovery evidence and Tushare as the value source, while this decision supersedes its trigger-resolution detail: one atomic full-history three-statement refresh resolves all pending announcements for an affected stock according to whether Candidate validation produces any Canonical delta. Exact announcement-date and report-period matches are audit metadata rather than authoritative links because provider publication versions need not align one-to-one with CNINFO disclosures. A successful no-delta refresh closes immediately while collection or validation failure stays pending; the existing `matched_source_version` resolution code and count value `5` remain constrained storage encodings rather than claims of an exact version link or five attempts, so no schema migration is required.
