# Resolve financial announcement triggers from stock-level Canonical deltas

One atomic full-history three-statement refresh resolves all pending Financial Announcement Triggers for an affected stock when validation either publishes a Canonical delta or confirms that no Canonical facts changed. Exact announcement-to-version matches remain audit evidence rather than resolution truth because CNINFO disclosures and Tushare statement versions need not align one-to-one; collection or validation failure leaves the triggers pending.
