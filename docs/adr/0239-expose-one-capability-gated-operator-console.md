# Grant one Operator capability without general RBAC

One active Researcher holds the indivisible Operator Capability, with initial assignment and transfer restricted to private administration. The Operator Console manages invitations, session revocation and separate data-refresh requests through session-bound, exact-action Operator Proofs under [ADR-0241](0241-keep-operator-authority-split-between-auth-and-core.md), whose confirmation requirements distinguish email-verified identity actions from Data Refresh operations. This provides limited product administration without a password-confirmation requirement, second administrator identity, general role hierarchy or unrestricted access to another Researcher's research.
