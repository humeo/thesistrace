# Share the current Authoring Reference between Console and MCP

Research Authoring owns one bounded, read-only reference for workflows, Alpha
syntax, Python SDK members and executable examples. Console HTTP and MCP call
that same module. Topic indexes discover exact symbols; individual reads return
complete entries, and unknown symbols explicitly return `found=false` with the
current index. The reference needs no ready Dataset or research reservation.

Compiler operator definitions, domain schemas, SDK source signatures, runtime
limits and existing executable templates supply the reference. SDK semantics
remain explicit beside authoring; coverage checks and real-guest example tests
detect drift without modifying the SDK's frozen execution identity. The live
Alpha Authoring Catalog supplies available fields and functions with independent
kind and keyword filters. Entry guidance and Tool descriptions make these
contracts accessible to external agents without repository access or private
Host prompts. Existing stateless admission, request identities, resource
ownership and permission boundaries remain authoritative.
