# Start an explicit DailyTrack from a successful ResearchRun

A DailyTrack starts only through an explicit action on a successful ResearchRun and fixes that Run, its frozen Research Definition, Dataset Release, and calculation contracts as its Tracking Origin. Dataset Publication never creates a Track automatically, activation is subject to the Active DailyTrack Limit, and a stopped Track is terminal rather than resumable.
