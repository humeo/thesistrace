# Make batch-versus-incremental equivalence the V1 end-to-end goal

V1's end-to-end correctness goal is that a Research Definition produces canonically equivalent Factor and Strategy results through reference execution and session-by-session DailyTrack execution over the same ordered Dataset Release sequence. The platform verifies this through explicit equivalence verification rather than replaying the complete history during every ordinary Advance.
