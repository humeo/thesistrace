# Use per-instrument Tushare financial collection

Complete-history bootstrap uses resumable ordinary Tushare endpoint-by-instrument collection and fails closed rather than switching to VIP or alternate request shapes. Daily Financial Refresh selects instruments from structured Financial Report Requirements and bounded full-history reconciliation, retaining atomic per-company three-statement acceptance and independent indicator collection under [ADR-0249](0249-discover-financial-reports-from-structured-disclosure-periods.md). The slower ordinary-source path is accepted for deterministic provenance and one deployable permission contract.
