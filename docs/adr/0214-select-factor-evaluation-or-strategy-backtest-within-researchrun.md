# Select Factor Evaluation or Strategy Backtest within ResearchRun

Factor Evaluation and Strategy Backtest run as separate ResearchRuns, sharing Data, Alpha, lifecycle, recovery, and publication boundaries without requiring each other's calculations. Factor Evaluation owns forward labels and signal statistics; Strategy Backtest and its DailyTrack compute the signals they need and simulate the portfolio without implicit Factor execution, results, or continuation state, so label availability does not govern account progress. Only Strategy Backtest accepts Strategy inputs and may seed DailyTrack; each Result contains its requested kind without empty placeholders for the other, and Batch-owned Runs preserve the same execution and Result boundaries.
