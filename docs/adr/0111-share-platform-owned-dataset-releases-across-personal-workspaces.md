# Share platform-owned Dataset Releases across Personal Workspaces

Hosted Platform V2 operates one Tushare ingestion and Dataset Publication flow and exposes each resulting immutable Dataset Release read-only to every Personal Workspace, whose private ownership begins with Research Definitions and their derived resources. This avoids duplicating identical ingestion and storage while preserving the platform/private ownership boundary, subject to Tushare authorization permitting hosted shared use.
