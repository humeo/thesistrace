# Make one immutable Result Bundle the ResearchRun truth

A successful ResearchRun publishes one immutable Result Bundle bound to its accepted input, Data Generation, calculation rules, and verified content; incomplete execution cannot expose a partial report as research truth. A Factor Result retains daily aggregate evaluation evidence, while a Strategy Result retains account observations, terminal holdings, target updates, and simulated order and fill evidence; DailyTrack holdings are read from its published account state. Daily Holding Observations are separate diagnostics retained for a limited period and renewed by actual detail reads, so expiry can reclaim them without invalidating a Result or Checkpoint; later investigation may use a new current-data Run without guaranteeing equality or rewriting the original Result, avoiding permanent detailed histories and historical-engine retention.
