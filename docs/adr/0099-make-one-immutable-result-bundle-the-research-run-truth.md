# Make one immutable Result Bundle the ResearchRun truth

A successful ResearchRun publishes one immutable Result Bundle bound to its accepted input, Data Generation, calculation rules, and verified content; incomplete execution cannot expose a partial report as research truth. A Factor Result retains daily aggregate evaluation evidence, while a Strategy Result permanently retains account observations and terminal holdings; its target, order, fill, adjustment and execution constraint payloads have a seven-day idle lifetime, renewed only by successful explicit event reads. Expiry moves diagnostic object references to verified inventory tombstones and reclaims unreferenced bytes, preserving the immutable manifest identity, report and Track seed; DailyTrack holdings are read from its published account state. Daily Holding Observations are separate diagnostics retained for a limited period and renewed by actual detail reads, so expiry can reclaim them without invalidating a Result or Checkpoint; later investigation may use a new current-data Run without guaranteeing equality or rewriting the original Result, avoiding permanent detailed histories and historical-engine retention.
